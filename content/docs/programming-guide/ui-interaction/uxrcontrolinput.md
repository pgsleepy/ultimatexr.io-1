# UxrControlInput

## Introduction

The `UxrControlInput` component, derived from Unity's `EventTrigger`, simplifies the handling of events triggered by UI controls in VR. It is the primary way to respond to user interactions with UI elements programmatically.

{{% callout info %}}
The full API can be explored in the [UxrControlInput API Reference](/api/T_UltimateXR_UI_UnityInputModule_UxrControlInput) and the user guide can be found in the [UI Interaction User Guide](/docs/ui-interaction/overview).
{{% /callout %}}

Key benefits include:
- **Event-driven UI code**: Subscribe to events generated by individual controls or use global static events to handle events from any control.
- **Extensibility**: New controls with more complex behavior can inherit from `UxrControlInput` and add their own logic. An example is `UxrToggleControlInput`.
- **Audio/haptic feedback**: Each control can specify feedback for click, press, and release events using `UxrControlFeedback`.

## Events

### Instance Events

These events are raised by a specific `UxrControlInput` instance:

- `Pressed`  
  Raised whenever the control is pressed.
- `Released`  
  Raised whenever the control is released after being pressed.
- `Clicked`  
  Raised whenever the control is clicked. A click can be a press or a release after a press, depending on the operating mode.
- `PressHeld`  
  Raised whenever the control has been pressed for `PressAndHoldDuration` seconds without being dragged.
- `DragStarted`  
  Raised whenever the control starts being dragged.
- `Dragged`  
  Raised each frame the control is being dragged.
- `DragEnded`  
  Raised whenever the control stops being dragged.
- `Dropped`  
  Raised whenever the control is dropped.
- `CursorEntered`  
  Raised whenever the pointer enters the control.
- `CursorExited`  
  Raised whenever the pointer exits the control.
- `UpdateSelected`  
  Raised whenever the selected control's input field is updated.
- `InputSubmitted`  
  Raised whenever the control's input field is submitted.

### Global Static Events

These events are raised whenever **any** `UxrControlInput` triggers the corresponding action:

- `GlobalPressed`
- `GlobalReleased`
- `GlobalClicked`
- `GlobalDragStarted`
- `GlobalDragged`
- `GlobalDragEnded`

### Example

```c#
// Subscribe to a specific button's click event
myButton.Clicked += (control, eventData) =>
{
    Debug.Log($"Button {control.name} was clicked!");
};

// Subscribe to any control being clicked
UxrControlInput.GlobalClicked += (control, eventData) =>
{
    Debug.Log($"A control was clicked: {control.name}");
};
```

## Properties

### State

- `bool` `IsDragging`  
  Gets whether the control is currently being dragged.
- `bool` `IsPointerOver`  
  Gets whether the pointer is currently over the control.
- `bool` `IsBeingPressed`  
  Gets whether the control is being pressed.
- `bool` `IsBeingDestroyed`  
  Gets whether the component is being destroyed during the current frame.
- `bool` `WasClicked`  
  Gets whether the control was clicked since the last time it was set to false.

### Configuration

- `bool` `Enabled`  
  Gets or sets whether the object can be interacted with and will send any events.
- `bool` `Interactable`  
  Gets or sets whether the widget is interactable. The widget should have a `Selectable` component.
- `float` `PressAndHoldDuration`  
  Gets or sets how many seconds need to pass to trigger a `PressHeld` event.
- `object` `Tag`  
  Gets or sets a custom data property that can be used to store arbitrary information.

### Unity References

- `GameObject` `GameObject`  
  Gets the control's GameObject.
- `RectTransform` `RectTransform`  
  Gets the Unity `RectTransform` component.
- `Image` `Image`  
  Gets the Unity `Image` component on the same object, if it exists.
- `ScrollRect` `ScrollRect`  
  Gets the `ScrollRect` reference used in drag/scroll events.

## Async Support

`UxrControlInput` provides async methods to wait for user interaction:

- `static Task<UxrControlInput>` `WaitForClickAsync(CancellationToken ct, params UxrControlInput[] controls)`  
  Waits asynchronously until any of the given controls is clicked. Returns the control that was clicked.
- `Task` `WaitForClickAsync(CancellationToken ct = default)`  
  Waits asynchronously until this specific control is clicked.

### Example

```c#
// Wait for any of three buttons to be clicked
UxrControlInput clickedButton = await UxrControlInput.WaitForClickAsync(ct, buttonA, buttonB, buttonC);
Debug.Log($"User clicked: {clickedButton.name}");
```

## Overridable Methods

When creating custom controls that inherit from `UxrControlInput`, the following methods can be overridden. Always call the base implementation at the beginning:

- `OnDragStarted(PointerEventData)`
- `OnDragged(PointerEventData)`
- `OnDragEnded(PointerEventData)`
- `OnDropped(PointerEventData)`
- `OnPressed(PointerEventData)`
- `OnReleased(PointerEventData)`
- `OnClicked(PointerEventData)`
- `OnCursorEntered(PointerEventData)`
- `OnCursorExited(PointerEventData)`
- `OnInputSubmitted(BaseEventData)`

## UxrControlFeedback

The `UxrControlFeedback` class defines audio and haptic feedback for a UI interaction event. Each `UxrControlInput` can specify a `UxrControlFeedback` for its press, release, and click events. The feedback includes:

- `AudioClip` `AudioClip`  
  The audio clip to play.
- `float` `AudioVolume`  
  The audio volume.
- `UxrHapticClipType` `HapticClip`  
  The haptic clip type to play.
- `float` `HapticAmplitude`  
  The haptic amplitude.

## UxrToggleControlInput

`UxrToggleControlInput` extends `UxrControlInput` to add toggle functionality. It works with Unity's `Toggle` component and provides additional features:

- Toggle state management with on/off colors.
- Integration with `UxrToggleGroup` for mutually exclusive toggle sets.
- State save/restore support.
